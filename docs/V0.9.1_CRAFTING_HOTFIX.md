# Mie Survival v0.9.1 — Crafting hotfix

v0.9.1 is a maintenance release based on v0.9.0.

## Fixed

- Fixed a long-standing crash when opening the crafting inventory with only one available recipe, commonly reproduced when wood/planks only exposed the stick recipe.
- Crafting recipe navigation now keeps the selected index inside the valid recipe range for one, two, or many recipes.
- Hover, selection, ingredient rendering, and crafting output lookup now validate recipe indexes before accessing the recipe list.
- The crafting slider now uses a signed recipe count, avoiding underflow/invalid positions for small recipe lists.

## Compatibility

- No recipe IDs were changed.
- No save format or world format changes were introduced by this hotfix.
- Existing v0.9.0 worlds and player data remain compatible.

## Release version

The source, CMake build version, Windows installer, launcher/runtime build and packaged `VERSION.txt` identify this release as `0.9.1`.
