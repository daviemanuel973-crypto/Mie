# v0.8.0 Recipe Discovery and Recipe Book

The Field Guide now contains a dynamic recipe book backed by the existing
103-entry crafting registry. Recipe indexes, ingredient costs and station
requirements remain unchanged, so multiplayer crafting packets and v0.7
progression stay compatible.

## Discovery rules

- The server records every valid block or item type that enters the player's
  inventory, cursor or armour slots.
- A recipe is revealed permanently after every ingredient type it needs has
  been found. Stack quantities are shown by the book but do not delay discovery.
- Recipes with the `anyWood` rule accept knowledge of any matching plank or log
  family, matching the actual crafting validator.
- Discovery changes what the standard client displays; it is not a security
  boundary. The authoritative server still checks recipe index, ingredients and
  required crafting station for every craft request.

## Persistence and compatibility

Discovery uses a compact bit set for the frozen v0.7 content ranges: 212 block
IDs and 145 item IDs fit into 45 bytes. A versioned 52-byte extension is appended
after the inventory armour data in save and network payloads. Older payloads
that end before this extension remain valid and start with an empty history;
materials already present in an old inventory are learned on the next server
update.

Invalid magic, versions, lengths and truncated payloads are rejected instead of
being partially applied. Air and unused type-ID ranges can never become known.

## Field Guide UI

The previous hard-coded Important Crafts page has been replaced by the recipe
book. It shows:

- discovered recipe count and known material count;
- result name and stack size;
- required crafting station;
- exact ingredient names and quantities;
- stable six-row pagination without exposing locked recipe names.

The one-time Field Guide objectives and automatic reward delivery remain on the
main page and are unchanged.
