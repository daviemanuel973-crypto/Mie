# Mie Survival v0.9.3 — authoritative gameplay stabilization

v0.9.3 stabilizes the v0.9.2 gameplay and performance base without changing
persisted item, block or entity type IDs.

## Corrected

- Block placement, breaking and interaction requests are checked against server
  world bounds and authoritative player reach.
- Rejected predicted block mutations restore the authoritative block and inventory.
- Remote paint and spawn-egg positions are rejected.
- Packet payload sizes are validated before block and chunk action data is read.
- Existing client raycasts keep their normal range with a small server tolerance
  for movement between packets.

## World creation

- New worlds can start in Survival or Creative mode.
- Survival remains the fallback for old, missing or invalid world-mode data.
- Existing player saves retain their own persisted mode.
- Creative world creation disables Hardcore to avoid contradictory settings.

## Validation

- Windows Release CI and Linux Flatpak CI passed before integration.
- Tests cover invalid heights, distant actions, non-finite positions and legacy
  world-mode fallback.
