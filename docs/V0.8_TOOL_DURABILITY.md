# v0.8 — Tool and Weapon Durability

This milestone turns the dormant item-metadata hook into a complete durability
loop for Survival tools and melee weapons.

## Rules

| Material | Maximum durability |
| --- | ---: |
| Gold | 96 |
| Training | 128 |
| Copper | 180 |
| Bronze | 240 |
| Silver | 260 |
| Lead | 280 |
| Iron | 360 |

- A tool loses one durability after a successful server-approved block break.
- A melee weapon loses one durability after a successful server-approved hit.
- A weapon does not wear when an attack misses, is rejected, targets a Creative
  player or only activates a training dummy.
- Creative players do not consume durability.
- At zero durability the item breaks and is removed immediately.
- The inventory and hotbar show a colour-coded durability bar. Hover text shows
  the exact remaining and maximum values.

## Save and multiplayer compatibility

Durability uses a small versioned record inside the existing item metadata.
That metadata already travels with player inventories, chests and dropped items,
so no player- or world-save format change is needed. Existing and newly crafted
items without this record are interpreted as unused at full durability. Unknown
legacy metadata on a durable item is sanitized to the same compatible full state.

Block breaks and attacks now carry the selected inventory slot and inventory
revision. The authoritative server validates both before applying the action,
changes durability only after a successful action and then synchronizes the
complete inventory. A modified client cannot choose its own remaining durability
or consume a different slot.

## Scope

Repairing items and durability enchantments are intentionally outside this
slice. Furnace fuel/progress processing is documented in
[`V0.8_FURNACE_PROCESSING.md`](V0.8_FURNACE_PROCESSING.md); recipe discovery,
farming expansion and beds remain later v0.8 milestones.
